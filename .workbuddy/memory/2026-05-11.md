# 2026-05-11 工作日志

## 二合一分支 merge-lede-immortal 创建完成

### 目标
将原先 master（LEDE/OpenWrt）和 immortalwrt 分支的编译逻辑合并为一个分支，支持通过 `-t/--target` 参数选择编译 openwrt(LEDE) 或 immortalwrt。

### 改动内容
1. **新建分支** `merge-lede-immortal`，基于 `origin/immortalwrt`
2. **Python 重写**：将 `build_with_docker.sh`、`package_firmware.sh`、`before_compile.sh`、`before_update_feeds.sh` 用 Python 重写：
   - `scripts/builder/config.py` — 常量、路径、仓库配置
   - `scripts/builder/source.py` — 源码克隆/更新（根据 target 选择仓库）
   - `scripts/builder/feeds.py` — feeds 更新、passwall/golang/rust 管理
   - `scripts/builder/kernel.py` — 内核查询、下载、解压
   - `scripts/builder/build.py` — make download + make 编译
   - `scripts/builder/package.py` — 打包（armv8/x86/mt798x）
   - `scripts/build.py` — 主入口，argparse 子命令（compile/package/download/menuconfig）
3. **`run_build_use_docker.sh` 更新**：支持 `-t/--target openwrt|immortalwrt`，调用 Python 脚本
4. **`.github/workflows/build.yml`**：CI 工作流，支持手动选择 target/device/config
5. **删除旧脚本**：`build_with_docker.sh`、`package_firmware.sh`、`before_compile.sh`、`before_update_feeds.sh`

### 架构设计
- 去掉了 commit_id 逻辑，默认拉最新代码
- 用 `argparse` 子命令代替位置参数，更清晰
- 用 `subprocess.run` 代替 `os.system`，错误处理更好
- 模块按职责拆分，每个文件 ~100 行，易维护
